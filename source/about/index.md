一个普通的计算机学习者，喜欢把想法做成能真正跑起来的东西。

做过的事情大致分三类。

## 写爬虫和工具

用 Python 抓过微博评论做数据清洗，按微博 ID 采集、剔除无效字符、规范化成 CSV。
也写过一个带图形界面的高清壁纸批量下载工具，支持九大分类、自定义页码、
智能文件管理与实时日志，Windows 上免安装即开即用。

## 做网站和小程序

独立写了一个响应式个人导航站，玻璃态外观、自适应布局，
集成了时钟、天气、IP 定位等接口，并为接口失效设计了降级容错。
也参与过一个微信记账小程序，前端用小程序原生框架，
后端是 Flask + MySQL，负责收支录入、账单列表与图表统计。

## 做一些不太技术的东西

用 Ren'Py 做了一个治愈向的文字游戏《奶奶的菜谱》，
用七道家常菜串起六十年的家族故事，通过切菜、火候、调味影响结局走向，
片尾还放了一节关于阿尔兹海默症早期识别的科普。
