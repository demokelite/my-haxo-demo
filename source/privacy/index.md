本页说明本站会收集哪些信息、如何使用，以及你可以怎么做。

## 一、本站会处理哪些信息

### 1. 访问统计（不蒜子）

本站使用 [不蒜子](https://busuanzi.ibruce.info/) 统计访问量，会记录：

- 页面访问次数（PV）与访客数（UV）
- 按域名区分的汇总计数

该服务**按域名聚合统计**，不建立个人画像。计数结果公开显示在侧边栏的「网站资讯」中。

### 2. 访客归属地与 IP 展示（侧边栏「小板报」）

本站侧边栏的「小板报」卡片会**在你自己的浏览器里**显示：

- 你当前出口 IP 的归属地（省 / 市 / 区县）
- 你的公网 IP 地址
- 你所在位置与本站博主的直线距离
- 当地天气

**这些信息只在你本机浏览器中计算和展示，本站服务器不会记录，也不会存储。**

实现方式：

| 用途 | 数据来源 |
| --- | --- |
| 获取公网 IP | 浏览器 WebRTC（STUN），若失败则由下列接口返回 |
| IP 归属地 | `uapis.cn`（经本站云函数转发）、`v2.xxapi.cn` |
| 天气 | `uapis.cn`（经本站云函数转发）、`api.open-meteo.com` |

也就是说，请求这些接口时你的 IP 会被**对应的第三方服务**看到。这是互联网上任何「显示你的归属地」功能的固有代价。

### 3. 评论（Twikoo）

本站评论系统使用 [Twikoo](https://twikoo.js.org/)。提交评论时：

- 你填写的昵称、邮箱、网址会被保存
- 评论内容与提交时间会被保存
- 为防刷与排查，可能记录提交时的 IP

评论数据保存在评论服务提供方的数据库中。**邮箱不会公开显示**。如需删除自己的评论或相关信息，可通过评论中的联系方式或邮件告知。

### 4. 本地存储

本站会在你的浏览器中使用 `localStorage` / `sessionStorage` 保存少量偏好，例如：

- 深色 / 浅色模式选择
- 侧边栏折叠状态
- 「小板报」的归属地与天气缓存（约 30 分钟，避免重复请求）

这些数据只存在你自己的浏览器里，你可以随时通过清除浏览器数据删除。

## 二、本站不做什么

- 不主动收集你的姓名、手机号等身份信息
- 不向第三方出售或共享访客数据
- 不在你未提交评论的情况下建立访客档案

## 三、第三方服务清单

| 服务 | 用途 | 隐私政策 |
| --- | --- | --- |
| 不蒜子 | 访问量统计 | — |
| uapis.cn | IP 归属地、天气 | 见其官网 |
| v2.xxapi.cn | IP 归属地（备用） | 见其官网 |
| Open-Meteo | 天气（备用） | https://open-meteo.com/en/terms |
| Twikoo | 评论系统 | https://twikoo.js.org/ |
| `cdn.cbd.int` | 前端静态资源 CDN | — |
| `model.hacxy.cn` | 看板娘（Live2D）模型 | https://github.com/hacxy/l2d-widget |

## 四、你的选择

- **不想被统计访问量**：可使用浏览器的广告拦截 / 脚本拦截插件，或开启「请勿跟踪」
- **不想显示归属地**：本站的归属地展示完全在前端进行，屏蔽对应脚本即可，不影响正常阅读
- **不想留下评论数据**：不提交评论即可；已提交的可以联系删除
