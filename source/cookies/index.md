这一页说明本站会在你的浏览器里存些什么、为什么存、怎么清掉。

写在前面：**本站不投放广告，不做行为追踪，也没有接入任何分析用户画像的服务。**

---

## 一、本站自己不使用 Cookie

经检查，本站自身**没有设置任何 Cookie**（没有调用过 `document.cookie`）。

替代方案是浏览器的**本地存储**（localStorage / sessionStorage）。它和 Cookie 的区别是：
存储在你自己电脑上，**不会被自动附加到每个网络请求里发给服务器**。

下面列出实际用到的每一项。

---

## 二、本站写入的本地存储

### 环境音控件的音量偏好

| | |
| --- | --- |
| 键名 | `ambient-player-v1` |
| 类型 | localStorage，长期保存 |
| 存了什么 | 七种环境音各自的音量、总音量 |
| 用途 | 下次打开时记住你调过的音量，不用重新调 |
| 会上传吗 | 不会。只存在你的浏览器里 |

### 访客小板报的临时缓存

| | |
| --- | --- |
| 键名 | 会话级临时键 |
| 类型 | sessionStorage，**关掉标签页就消失** |
| 存了什么 | 你的归属地和天气查询结果 |
| 用途 | 十分钟内重复打开页面时不必反复请求接口 |
| 会上传吗 | 不会 |

## 三、主题写入的本地存储

页面主题（安知鱼）为了记住你的操作习惯，会写入以下几项，**全部只存在于你的浏览器**：

| 键名 | 用途 |
| --- | --- |
| `commentBarrageSwitch` | 是否关闭了评论弹幕 |
| `keyboardToggle` | 无障碍快捷键的开关状态 |
| `musicData` | 音乐播放器的状态 |
| `randomPostClick` / `randomPostTimes` | 「随便逛逛」的点击记录，用于避免连续跳到同一篇 |

## 四、评论系统

评论区使用 Twikoo，数据存在博主自建的数据库里。

- 你填写的**昵称、邮箱、网址和评论内容**会保存到服务器，用于展示评论
- 邮箱**不会公开显示**，仅用于识别身份和接收回复通知
- 你登录评论管理后台时会获得一个**临时访问令牌**，存在浏览器本地，用于保持登录状态
- 评论系统**不设置第三方追踪 Cookie**

如果不希望留下任何信息，不填写即可，浏览文章不需要评论。

## 五、第三方请求

打开页面时，浏览器会向以下第三方发起请求。这些请求**可能被对方记录访问日志**（包括你的 IP），
但本站没有要求它们返回任何用户画像数据：

| 来源 | 用途 |
| --- | --- |
| `cdn.cbd.int`、`npm.elemecdn.com` | 加载脚本、样式和图标字体等静态资源 |
| `busuanzi.ibruce.info` | 全站访问量计数 |
| `v2.xxapi.cn`、`api.open-meteo.com` | 小板报查询归属地和天气 |
| `model.hacxy.cn` | 看板娘的模型文件 |

其中访问量计数由第三方提供，本站无法控制它的统计方式。如果介意，可以在浏览器里拦截该域名，**不影响其余功能**。

---

## 六、怎么清除

想删掉本站存的东西：

- **只删本站的**：浏览器开发者工具 → Application → Storage → 清除本站的 Local Storage 和 Session Storage
- **全都删掉**：用浏览器的「清除浏览数据」，勾选 Cookie 和网站数据
- 也可以用**无痕模式**浏览，关闭窗口后自动清空

清掉之后，环境音音量会回到默认值，其余功能不受影响。
