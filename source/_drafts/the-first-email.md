每天早上打开电脑，第一件事多半是刷邮箱。垃圾邮件、周报、验证码、各种催命符塞满收件箱。

可要是有人问你，**人类历史上第一封电子邮件到底写了什么**，答案可能会让你愣一下——

**发这封邮件的人，自己都不记得了。**



## 一、两台并排摆着的「大块头」

时间回到 1971 年底，美国马萨诸塞州剑桥市，BBN 公司的办公室里。

工程师雷·汤姆林森（Ray Tomlinson）对着两台并排摆着的 PDP-10 大型机，琢磨一个副业项目。

那会儿 ARPANET 刚跑起来没两年。计算机是机房里供着的稀罕物，一台机器多个用户通过终端分时共用。

**本机内留言早就有了。** 有个叫 `SNDMSG` 的程序，能给同一台机器上的其他用户留个便条——本质就是往对方的「邮箱文件」末尾追加一段文字。

**但跨机器发消息，没人做过。**

汤姆林森干的事，用今天的话说叫「缝合怪」：他把另一个用来传输文件的程序 `CPYNET` 的代码 patch 进了 `SNDMSG`，让消息能顺着网络跑到另一台机器上。

两台 PDP-10 就挨在一起，网线里的旅程也就**十五英尺，大约四米五**。收件人是他自己。

## 二、键盘上唯一的「介词」

跨机器送信，地址得写清楚「谁」在「哪台机器」上，中间需要一个分隔符。

汤姆林森盯着面前 Model 33 电传打字机的键盘扫了一圈，挑中了 `@`。

理由特别朴素：

- 这符号**没人会往用户名里塞**，不会产生歧义
- 它念作 at，正好是「某人在某主机」的意思

他后来开玩笑说，`@` 是键盘上唯一一个介词。

就这么个几乎拍脑袋的决定，印在了此后几十亿张名片上。

> 顺带一个冷知识：`@` 这个字符不是他发明的。早在 1885 年的安德伍德打字机上就有了，原本是会计速记符号，表示「以……单价」。
>
> 到了各国它还收获了一堆外号——法国人叫它「蜗牛」，德国人叫它「猴子尾巴」，我们这边管它叫「小老鼠」。

## 三、「测试消息太没存在感，所以我把它们忘了」

重头戏来了：第一封邮件的正文到底写了什么？

汤姆林森晚年反复被问这个问题。他的原话大意是：

> 那些测试消息完全不值得记住，所以我已经把它们忘了。

2009 年《纽约时报》采访他，他还是这么说的——消息是从一台机器发到另一台机器的，内容早忘干净了。

**据公开资料和他本人的推测**，当时他随手敲的，大概率是键盘字母区最上面一排顺过去的字符：

```
QWERTYUIOP
```

**注意，是「大概率」。** 这串字符没有任何含义，纯粹是测试时手往键盘上一搭的产物。

后世有无数文章斩钉截铁地写「第一封邮件内容就是 QWERTYUIOP」，其实属于以讹传讹——**他本人从没确认过。**

## 四、这件事最打动我的地方

我第一次知道这茬的时候愣了好一会儿。

**人类这么重要的「第一次」，没有演讲、没有金句、连个截图都没存下来。**

就因为在当事人眼里，这玩意儿根本不算个成果。据说他做完还特意叮嘱同事别声张，因为这是他摸鱼搞的副业，不是上头派的正经活儿。

这种「无心插柳改变世界」的剧情，在技术史上反而是常态。

## 五、祖传协议，活到了今天

后面的事大家都熟：


| 时间 | 事件 |
| ---- | ------------------------------------ |
| 1972 | 汤姆林森为 `@` 方案写了正式文档，邮件在 ARPANET 上迅速传开 |
| 1982 | SMTP 协议定稿（RFC 821），邮件有了统一的投递规则 |
| 之后 | POP3、IMAP、Hotmail、Gmail，一路走到今天 |


到今天，电子邮件的底层逻辑跟 1971 年那套比，**骨架几乎没动**：用户名 `@` 主机，消息投递到对方邮箱。全球邮件用户超过五十亿，验证码、账号注册、职场公文，照样离不开它。

哪怕各种即时通讯工具轮番喊着要「杀死邮件」，这老东西依旧稳如泰山。

**这就是典型的技术历史包袱。** 你能挑出 SMTP 一百个毛病——默认不加密、伪造发件人容易、垃圾邮件泛滥——但全世界的服务器都按这套规矩跑，谁也掀不动。

祖传代码不一定优雅，**活得久本身就是一种实力。**

汤姆林森 2016 年去世，享年 74 岁。他没看到 AI 帮人写邮件写得比人还溜的今天。
